🏛️ Du Lich Tra Vinh API

RESTful API Documentation v1.0.0

Complete CRUD operations for Tourism Management System

🔐 Authentication: Most endpoints require JWT token in Authorization header: Bearer <token>

📊 System Information

GET /health

Health check endpoint - returns server status

GET /api/info

API information and available endpoints

🔐 Authentication

POST /api/auth/register

Register new user account

Body: { "username": "string", "email": "string", "password": "string" }

POST /api/auth/login

Login user and get JWT token

Body: { "email": "string", "password": "string" }

POST /api/auth/logout

Logout current user (requires auth)

GET /api/auth/session

Get current session info (requires auth)

👥 User Management

GET /api/users

Get all users (Admin only)

Query: ?page=1&limit=10&search=keyword

GET /api/users/profile

Get current user profile (requires auth)

PUT /api/users/profile

Update current user profile (requires auth)

Body: { "name": "string", "email": "string" }

PUT /api/users/password

Change password (requires auth)

Body: { "currentPassword": "string", "newPassword": "string" }

🏛️ Location Management

GET /api/locations

Get all locations

Query: ?page=1&limit=10&search=keyword&category=type&sort=field

GET /api/locations/search

Search locations

Query: ?q=keyword&category=type&minPrice=0&maxPrice=100&minRating=4

GET /api/locations/category/:category

Get locations by category

Categories: DiTich, ChuaDen, KhuDuLich, AmThuc, KhachSan

POST /api/locations

Create new location (Admin only, supports file upload)

Body: FormData with location fields and optional image file

PUT /api/locations/:id

Update location (Admin only)

DELETE /api/locations/:id

Delete location (Admin only)

📁 File Upload

POST /api/uploads/image

Upload image file (requires auth, max 5MB)

Body: FormData with 'image' field

DELETE /api/uploads/:filename

Delete uploaded file (Admin only)
